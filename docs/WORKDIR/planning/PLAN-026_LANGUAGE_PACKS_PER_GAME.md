# PLAN-026: A language pack per game (Generals and Zero Hour)

Status: **agreed with the owner 05/10/2026, waiting for releases.** Both steps are done **at a
release**, never in a test build. Before every release, check which step is due here.

## Why

The packs are translations of Zero Hour's string table (`languages/<language>/generals.str`).
Measured on the retail tables: Zero Hour's generals.csf holds 2786 of the base game's 2806 labels,
and their meaning differs in ~210 (credits, balance tooltips, the game's name, hotkey letters);
the 20 labels only Generals has come from the game's own generals.csf since a12. So a Zero Hour
pack serves Generals well enough, but not exactly -- "Exit Zero Hour", Zero Hour's upgrade numbers.
The owner wants a file per game, so each can be corrected separately.

Target layout (owner's choice), one folder per language as now:

- `languages/<language>/generals.str` -- **Generals** (base game)
- `languages/<language>/generalszh.str` -- **Zero Hour**

On a device the file is always installed as `<game folder>/data/<language>/generals.str` (the name
the engine reads); the two games have different game folders, so nothing is ever deleted or forced
to re-download -- the "Download translation" button fetches the current file as always.

The catch: launchers up to the current release download `generals.str` **for Zero Hour**. That is
why this goes in two steps.

## Step 1 -- at the next release

- Add `languages/<language>/generalszh.str` to every pack: a copy of today's `generals.str`.
  From then on Zero Hour translations are edited in `generalszh.str`.
- `generals.str` stays a copy of the Zero Hour text, kept in sync with `generalszh.str` (a script
  or by hand), so released launchers keep working exactly as before.
- Launcher: Zero Hour downloads `generalszh.str`; Generals downloads `generals.str`. Both are
  installed as `data/<language>/generals.str` in that game's folder.
- `languages/README.md`: the two files, which one a translator edits.
- Strings: none (the button and its texts are unchanged).

## Step 2 -- at a later release, when the owner says most players have updated

- Replace `generals.str` with the real Generals translation, generated by a script: for each
  label of the base game's generals.csf, take the pack's Zero Hour translation where the English
  text is the same (~2570 labels); translate the ~210 that differ and the 20 Generals-only ones
  in all 12 languages; keep `GX:` labels.
- New launchers need no change (they already fetch `generals.str` for Generals).
- Launchers older than step 1 would then get the Generals text for Zero Hour: labels missing from
  it fall back to English (engines with the a12 fallback, including hot-updated ones) or show
  `MISSING` (older engines). That is the reason to wait.
- Stop syncing `generals.str` from `generalszh.str`.
